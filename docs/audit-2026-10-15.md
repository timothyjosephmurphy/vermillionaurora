## Other notes

- `rg` skips `.github` by default. Use `rg --hidden` when removing a feature; #535 missed PAYPAL_MODE checks in workflows because of this.
- Release-gate concurrency is per-PR, so three PRs run at once on shared runners. Expect queueing at busy times.
- The wall and gallery tests mock the network per host. When a new asset host is added, update every browser-test router. #539 broke the gallery-wall browser test this way.
